# Saurabh Kumar 3D Portfolio - Frontend

High-performance, futuristic 3D developer & data analytics portfolio built with React 18, Vite, Three.js, React Three Fiber, Framer Motion, and Tailwind CSS.

## Features
- **Interactive 3D Hero Scene**: Custom procedural WebGL scene built using Three.js, React Three Fiber (`@react-three/fiber`), and `@react-three/drei` with mouse parallax tracking, orbiting tech cubes, particle ring, and CSS 3D fallback for low-power devices.
- **Glassmorphism & Cyber Aesthetics**: Futuristic dark theme with glowing neon borders, subtle gradients, and backdrop blur.
- **Dynamic Typewriter Headline**: Cycling roles ("Data Analyst", "MERN Stack Developer", "Full Stack Developer").
- **Animated Statistics Counters**: Responsive viewport-triggered counters for completed projects, technologies, and hours.
- **Interactive Technical Arsenal**: Categorized skill inventory (Frontend, Backend, Database, Data Analytics, Tools) with realistic proficiency bars and brand icons.
- **Filterable & Searchable Projects**: Project cards with 3D hover tilt, direct Live Demo/Code buttons, and an interactive Project Details modal & dedicated page route.
- **Animated Experience Journey**: Vertical timeline connecting education, internships, certifications, and freelance projects.
- **Interactive Contact Form**: Client-side validation, direct API submission to backend, and celebration confetti animation.
- **Desktop Custom Cursor**: Smooth magnetic-style ring follower with interactive hover states (auto-disabled on mobile/touch screens).
- **Persistent Theme Toggle**: Seamless transition between dark and light themes with `localStorage` memory.
- **Initial Loading Screen**: Animated "SK" monogram and progress indicator.
- **Centralized Data File**: Easily edit portfolio details, projects, skills, certificates in `src/utils/portfolioData.js`.

## Getting Started
```bash
cd frontend
npm install
npm run dev
```

For production build:
```bash
npm run build
npm run preview
```
