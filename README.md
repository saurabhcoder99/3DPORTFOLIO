## 📂 Project Structure
```text
portfolio/
├── frontend/             # React 18 + Vite + Tailwind CSS + Framer Motion
│   ├── src/
│   │   ├── components/   # UI components, 3D Canvas, Navbar, Modal, etc.
│   │   ├── sections/     # Hero, About, Skills, Projects, Experience, Services, Contact
│   │   └── utils/        # Portfolio & career datasets, API integrations
│   └── public/           # Profile portraits, certificates, PDFs
└── backend/              # Node.js + Express.js + MongoDB API
    ├── controllers/      # Project controllers & live GitHub auto-sync logic
    ├── routes/           # REST API endpoints
    └── models/           # Mongoose schemas
```

## ⚡ Quick Start

### 1. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on: `http://localhost:5173/`

### 2. Backend Setup
```bash
cd backend
npm install
npm start
```
Backend runs on: `http://localhost:5000/`
